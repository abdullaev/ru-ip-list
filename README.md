# ru-ip-list

Russian IP address blocks (IPv4 + IPv6), mirrored daily from [ipdeny.com](https://www.ipdeny.com/).

| File | Source | Format |
|------|--------|--------|
| `ipv4.txt` | https://www.ipdeny.com/ipblocks/data/countries/ru.zone | one CIDR per line |
| `ipv6.txt` | https://www.ipdeny.com/ipv6/ipaddresses/blocks/ru.zone | one CIDR per line |
